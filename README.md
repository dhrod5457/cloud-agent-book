# AI Agent Ready Software Engineering

AI 코딩 에이전트가 프로젝트를 이해하고, 개발하고, 테스트하고, 검증하며, 여러 에이전트가 병렬 협업할 수 있도록 소프트웨어 프로젝트와 개발 프로세스를 설계하는 방법을 정리하는 책 프로젝트입니다.

가제: **AI Agent Ready Software Engineering**

한국어 부제 후보: **AI 코딩 에이전트 시대의 소프트웨어 설계와 개발**

## 집필 원칙

- 책 전체를 한 번에 작성하지 않습니다.
- Phase 단위로 설계, 검토, 작성합니다.
- 프로젝트 파일을 Source of Truth로 사용합니다.
- 특정 AI 제품 사용법보다 지속 가능한 소프트웨어 설계 원칙을 중심으로 다룹니다.
- Java/Spring Boot를 주요 실전 예제로 사용하지만 특정 언어나 제품에 종속되지 않는 원칙을 목표로 합니다.
- 제품 기능을 설명할 때는 최신 공식 문서를 확인합니다.

## 현재 상태

Phase 1 방향 정의를 완료했고, Phase 2 전체 목차 설계를 진행합니다.

자세한 진행 상태는 `STATUS.md`에서 관리합니다.
